# CC0 Shirtless Fighter Character Assets

- **Source:** [`kblood/CharacterCreator`](https://github.com/kblood/CharacterCreator) (`output/*.glb`, MakeHuman CC0 system pack), compressed with `gltfpack -cc -kn -km -ke`.
- **License:** **CC0-1.0** (Public Domain — MakeHuman CC0 system assets as documented in `output/asset_licenses.json` and the upstream repository).
- **Files:**
  - `base_body.glb` — MakeHuman 53-bone humanoid mesh with morph targets (`gender_male`, `muscle_max`, `weight_max`, `height_tall`) and PBR skin maps.
  - `clothing_shorts.glb`, `clothing_jeans.glb`, `clothing_boots.glb` — Modular lower-body garments bound to the shared 53-bone skeleton.
  - `hair_short02.glb`, `hair_short04.glb` — Modular short hair meshes bound to the shared 53-bone skeleton.
