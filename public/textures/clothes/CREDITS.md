# Clothes & Suit Texture Packs

All clothes PBR textures are CC0 (public domain) from [ambientCG](https://ambientcg.com), sourced from the GitHub CC0 mirror repositories [`zuujis-cc0/ambientcg-materials-fabric-2`](https://github.com/zuujis-cc0/ambientcg-materials-fabric-2) and [`zuujis-cc0/ambientcg-materials-fabric-3`](https://github.com/zuujis-cc0/ambientcg-materials-fabric-3).

Each pack provides 1024×1024 `color.jpg`, `normal.jpg` (NormalGL), `rough.jpg`, and `ao.jpg` maps:

| Folder | Asset | GitHub Source | Intended Use |
|---|---|---|---|
| `suit_wool` | `Fabric030` | `zuujis-cc0/ambientcg-materials-fabric-2` | Tailored worsted suit wool (matte weave) |
| `suit_twill` | `Fabric063` | `zuujis-cc0/ambientcg-materials-fabric-3` | Heavy matte wool twill suiting |
| `suit_linen` | `Fabric066` | `zuujis-cc0/ambientcg-materials-fabric-3` | Tailored summer wool/linen suiting |
| `shirt_cotton` | `Fabric061` | `zuujis-cc0/ambientcg-materials-fabric-3` | Crisp matte dress shirt cotton |
